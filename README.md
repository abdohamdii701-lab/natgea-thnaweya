# 🎓 موقع نتيجة الثانوية العامة 2026 - نظام الاستعلام السريع

موقع إلكتروني فائق السرعة للاستعلام عن نتائج الثانوية العامة برقم الجلوس أو باسم الطالب، يعتمد على محرك SQLite المفهرس للبحث السريع (أقل من 5 مللي ثانية) بين أكثر من 919 ألف طالب وطالبة.

## 🚀 المميزات
- **استعلام فوري برقم الجلوس:** عرض النتيجة التفصيلية والنسبة المئوية والتقدير العام.
- **بحث مرن بالاسم:** إمكانية البحث بأسماء الطلاب مع الترتيب حسب الأعلى مجموعاً.
- **قائمة أوائل الجمهورية:** عرض تلقائي لأعلى الدرجات المتفوقة.
- **بطاقة نتيجة رسمية قابلة للطباعة:** طباعة النتيجة بتنسيق شهادة رسمية.
- **مشاركة النتيجة:** نسخ تفاصيل النتيجة بنقرة واحدة أو مشاركتها عبر واتساب.
- **مظهر متجاوب:** يدعم المظهر الليلي والنهاري (Dark/Light Mode).

## 🛠️ التكنولوجيا المستخدمة
- **Backend:** Python (Flask) + SQLite (Indexed Engine)
- **Frontend:** HTML5, CSS3 (Vanilla Glassmorphism), JavaScript (ES6+), Canvas Confetti

## 📥 طريقة التشغيل محلياً
1. تثبيت المتطلبات:
   ```bash
   pip install flask pyodbc pandas
   ```
2. تشغيل السيرفر:
   ```bash
   python app.py
   ```
3. الدخول إلى الموقع عبر المتصفح:
   `http://localhost:5000`
